# Social Platforms Cheat Sheet

Norms change; treat these as defaults and follow the user's own data if they have it.

## Platform norms

| Platform | Best for | Text length | Formats | Notes |
|---|---|---|---|---|
| Instagram | Visual brand, B2C | Caption: hook in first 125 chars; up to ~2,200 | Reels (9:16), carousels (4:5), stories | 3-5 relevant hashtags; carousels drive saves; Reels drive reach |
| Telegram | Communities, media, expert brands | 500-1,500 chars typical, up to 4,096 (1,024 with media) | Text posts, polls, video circles, albums | Formatting (bold, links) matters; no hashtags culture; posting time consistency |
| VK | CIS B2C, communities | 300-1,500 chars | Posts, clips, articles, stories | Clips similar to Reels; communities and comments drive reach |
| LinkedIn | B2B, personal brand, hiring | 800-1,500 chars; hook before "see more" (~210 chars) | Text, documents (PDF carousels), polls | Personal story + lesson performs well; links in comments |
| TikTok / Reels / Shorts | Reach, younger audiences | Short caption | 15-60 s vertical video | Hook in first 1-2 s; captions on screen; trend audio |
| X (Twitter) | News, tech, discussion | 280 chars / threads | Threads, polls | Strong opinion + specifics; threads for depth |
| Facebook | 35+ audiences, groups, local business | 40-250 chars perform best | Posts, groups, events | Groups and ads more valuable than organic page reach |
| YouTube | Search, long-form education | Title ≤ 60 chars, description with keywords | Long video, Shorts | Title + thumbnail = the hook |

## Short video script template

```
Format: [Reels/TikTok/Shorts], [duration]
Hook (0-2 s): [on-screen text + spoken line]
Problem (2-7 s): ...
Value / demo (7-25 s): 3 fast beats, each with on-screen text
Proof (optional): ...
CTA (last 3 s): ...
Visual notes: shots, transitions, captions, audio
```

## Post template (text platforms)

```
[Hook: tension, surprising fact, question, or bold claim]

[Context: 1-2 short paragraphs]

[Value: list / steps / story with a lesson]

[CTA: one clear action]
```

## Content pillars examples

- Educational: how-tos, mistakes, checklists, myths
- Engagement: polls, questions, "this or that", UGC
- Proof: cases, reviews, numbers, before/after
- Behind the scenes: team, process, values
- Selling: offer, limited promo, objection handling

## Engagement mechanics

Ask an easy-to-answer question; reply to comments in the first hour; pin the best comment; repurpose top posts into other formats (post → carousel → video → newsletter).
