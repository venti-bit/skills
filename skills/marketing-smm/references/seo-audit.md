# SEO Audit

> Adapted (modified) from [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) `marketing/skills/seo-audit`, Apache-2.0.

Inputs: site URL or topic; audit type (full · keyword research · content gaps · technical · competitor comparison — default full); target keywords; competitors (if none, find 2-3 via web search). Consider the target search engines and market (e.g. Google, Yandex, Bing) — ranking factors and tools differ.

Without an SEO tool (Ahrefs, Semrush, Yandex Wordstat, Search Console), volume and difficulty are estimates from web research — label them as such and suggest connecting a tool or exporting data for precision.

## 1. Keywords
For each opportunity: primary vs. secondary, long-tail, question queries ("how to…", "what is…"), relative demand (high/med/low), difficulty (easy/moderate/hard), intent (informational / navigational / commercial / transactional).

## 2. On-page (key pages)
- Title 50-60 chars, unique, with target keyword
- Meta description 150-160 chars, compelling, with CTA
- Exactly one H1 with the primary keyword; logical H2/H3
- Keyword in the first 100 words, natural use, no stuffing
- Internal links with descriptive anchors; no orphan pages
- Image alt text; clean readable URLs

## 3. Content gaps
Topics competitors rank for and the site lacks; stale pages (12+ months); thin pages; missing formats (guides, comparisons, glossaries, tools, templates); funnel stages without content; topic-cluster / pillar opportunities.

## 4. Technical
Page speed and Core Web Vitals (LCP, INP, CLS) · mobile usability · structured data (FAQ, HowTo, Product, Article, Organization, Breadcrumb) · robots.txt, XML sitemap, canonicals, noindex · broken links and redirect chains · HTTPS and mixed content · indexation and duplicates · hreflang for multilingual sites.

## 5. Competitors
Keyword overlap and gaps, authority signals (referring domains), content depth and publishing frequency, link-worthy assets, SERP features owned (snippets, People Also Ask, images), technical advantages.

## Report
1. **Executive summary** — 3-5 sentences: biggest strength, top 3 priorities, overall verdict (strong / needs work / critical issues)
2. **Keyword opportunities** (15-25) — keyword | difficulty | opportunity (H/M/L) | current position | intent | content type
3. **On-page issues** — page | issue | severity (Critical / High / Medium / Low) | fix
4. **Content gaps** — topic | why it matters | format | priority | effort (quick win / half day / multi-day)
5. **Technical checklist** — check | pass/fail/warning | details
6. **Competitor comparison** — dimension | you | competitor A | B | winner
7. **Action plan** — Quick wins this week (titles, metas, broken links, alt text) and strategic investments this quarter (clusters, pillar pages, link building, restructuring), each with impact, effort, dependencies

Follow-ups to offer: content briefs for top keywords, rewritten titles/metas, a content calendar from the gaps.
